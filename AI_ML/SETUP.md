# Setup Guide

Follow these steps to set up your Python environment.

## Windows

1. Make sure Python is installed and added to PATH.
   
   Check with:
   ```cmd
   python --version
   ```

1. Open PowerShell.

2. Navigate to the AI_ML folder (where setup.bat is):
   ```cmd
   cd ./AI_ML
   ```
3. Run the setup script:
   ```cmd
   ./setup
   ```

# To Run Backend:
1. Navigate to AI_ML folder
    ```cmd
    cd ./AI_ML
    ```
2. type in powershell
```cmd
    ./run_backend
```
